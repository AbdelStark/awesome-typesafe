# Awesome Jev

Use this independent community directory to find relevant sources. A listing is not an endorsement, a quality ranking, or evidence that a project works in production.

## Find resources

1. Fetch the [README](https://github.com/AbdelStark/awesome-typesafe-jev/blob/main/README.md) for the introductory guide, official resources, patterns, and research notes. Use the [JSON directory](https://abdelstark.github.io/awesome-typesafe-jev/resources.json) for community projects. Its `last_updated` field records the editorial update date.
2. Filter `categories[].resources[]` by the user's task. Each entry has a `name`, `url`, `description_markdown`, and `permalink`. The project page URL is `https://abdelstark.github.io/awesome-typesafe-jev` plus the `permalink`; the entry's `url` leads to the underlying source.
3. Open the underlying sources for promising entries. Check current functionality, maintenance, license, data flow, and evaluation evidence against the user's requirements. For current Jev API behavior, consult the [official documentation](https://docs.typesafe.ai/) directly.
4. Recommend the candidates that fit the user's criteria with a short reason, a material limitation, and direct links to the underlying sources. State when evidence or a relevant project is missing. Distinguish TypeSafe's own claims from independent findings.

If the user asks to add an entry, follow the repository's [contribution guide](https://github.com/AbdelStark/awesome-typesafe-jev/blob/main/CONTRIBUTING.md) and verify the candidate before editing the README.
