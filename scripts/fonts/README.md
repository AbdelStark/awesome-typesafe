# Fonts for generated project cards

The card exporter uses Inter and Space Mono from [Google Fonts](https://github.com/google/fonts) at commit `e44c4b011a820c2cbe2fd2cfa8052037d7edb571`. Both are licensed under the SIL Open Font License 1.1. Their respective license texts are in this directory.

These fonts are build inputs for generated PNGs; the website does not load them.
